# Convert to SVG

Convert a [[raster image]] to a [[vector image]] ([[Scalable Vector Graphics|SVG]]).

## Recommended Free Tools
- **Adobe Express:** Free [Convert to SVG](https://express.adobe.com/tools/convert-to-svg/#) (outputs larger SVG files, ~1.7 MB).
- **SVGOMG:** [SVGOMG Web Optimizer](https://jakearchibald.github.io/svgomg/) to optimize and compress SVG down to ~66 KB (source JPG was 90 KB).

## Useful Converter Features
- Display file size preview before download, updating in real time on parameter regeneration.
- Parameter controls for level of detail, path smoothing, and color palette reduction.
