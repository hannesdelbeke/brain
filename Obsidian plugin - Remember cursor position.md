[GitHub](https://github.com/dy-sh/obsidian-remember-cursor-position)

Saves and restores the exact cursor position, scroll offset, and text selection for each note. 

Prevents Obsidian from resetting cursor focus to line 1 (`pos: 0`) on file open, avoiding raw markdown unmasking on top-line callouts in Live Preview.
