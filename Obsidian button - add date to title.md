Implemented as a custom [[Obsidian plugin]] to speed up note-creation flow. It allows me to start writing immediately without worrying about manual title formatting.

- **Filepath:** `.obsidian/plugins/add-date-prefix/main.js`
- **Description:** A custom Obsidian command that automatically prefixes the current note's title with today's date (`YYYY-MM-DD`). If a date is already present, it skips the modification.
- **Trigger:** Accessible via the Command Palette (`Ctrl/Cmd + O`) -> "Add Date Prefix to Title".

This acts as a seamless stop-gap solution for unstructured notes, avoiding the friction of [[random title note flow]].
