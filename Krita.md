# Krita

[[Krita]] is a free and open-source raster graphics editor designed primarily for digital painting and 2D animation.

## Key Features & Linux Integration
- **Cross-Platform:** Native Qt-based graphics pipeline with full Wayland and X11 support.
- **Hardware Acceleration:** OpenGL and Direct3D canvas rendering engines.
- **Brush Engine:** Advanced brush engines including Pixel, Smudge, Curve, and Particle, with configurable smoothing algorithms (Basic, Weighted, Stabilizer).
- **Stylus & Tablet Support:** Native `libinput` / `wl_tablet_v2` integration supporting pressure, tilt, and multi-touch gestures.
