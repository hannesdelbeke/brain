# Git Author

In [[git]], the **Author** field records who originally wrote the content, while the **Committer** field records who applied or committed the change.

In human-AI collaborative [[personal knowledge management|PKM]] vaults, tracking whether edits were written by a human or an AI model preserves knowledge [[provenance]] and historical context:

* **AI Co-Authorship:** Use standard GitHub trailers to attribute AI contributions alongside human edits. See [[public/github co-authors for AI|github co-authors for AI]].
* **Automated Sweeps & Uncommitted Work:** How agents handle uncommitted human edits in the working tree. See [[public/autocommit leftover changes|autocommit leftover changes]].
* **Line Provenance Across Refactors:** Tracing line authorship across note extractions and refactors. See [[public/human vs AI git history transfers between notes|human vs AI git history transfers between notes]].
