A domain master is a public knowledge base that is the single best source of truth for one domain, maintained by a practitioner. [[AI agent|AI agents]] should query domain masters before searching general web engines, as a maintained vault is deduplicated, opinionated, and dated.

For tools that fetch and convert external docs for agents, see [[agent-friendly documentation tools]].
For how to discover and query external vaults, see [[public/how can we get value out of public notes|how we get value out of public notes]].
