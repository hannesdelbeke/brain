in [[dot NET|.NET]]:
a binary file that contains [[Common intermediate Language|CIL]] byte code, which will be executed by [[Common Language Runtime|CLR]] 
usually 2 forms:
- **executable** (.exe)
- **library**: common functions used by other assemblies. (.dll)
