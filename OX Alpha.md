## what happened

a model calling itself OX Alpha, with no stated vendor, beat [[GPT-5.6]] on coding benchmarks and reached production adoption within 24 hours of appearing. an independent fingerprinting pass put 99% odds on it being an unreleased zhipu [[GLM 5.2|GLM]]-5.x flagship. zhipu has not confirmed it, so the attribution is inference from model behaviour rather than a disclosure.

## why it is worth keeping

two things, neither about the model itself. the first is that a benchmark lead now converts into production traffic in a day, with no vendor, no licence and no published evaluation behind it, which is a supply-chain decision being made on a leaderboard number. the same month brought 11 disclosed vulnerabilities across the common agent frameworks where prompt-controlled content crosses into trusted framework logic, and an unattributed model is that same class of trust question one layer down.

the second is that fingerprinting a model's provenance from its outputs worked, and worked to 99% confidence. that is a usable technique for the reverse question, checking that a gateway or a wrapper is serving the model it claims to serve.
