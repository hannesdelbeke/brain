## what is known

roughly 2.8T parameters, from moonshot AI, shipped inside the same three-week window as [[qwen3.8-max]] and [[GLM 5.2]]. that puts it above qwen3.8-max's 2.4T, which had been described as the largest open-weight release to date days earlier, and the active-parameter count that would say what it costs to run is not recorded.

parameter count on its own says almost nothing about capability in a mixture-of-experts release, only how much memory the weights need. GLM 5.2 is a quarter of kimi K3's size and is the model of that wave people report as the reliable agentic coder, so the ranking by size and the ranking by usefulness are not the same list.
