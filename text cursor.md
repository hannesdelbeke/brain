A text cursor (also called a caret or insertion point) indicates where text input will appear or where active line-focus resides in an editor.

Unlike a mouse cursor (pointer) that follows physical movement across the screen, a text cursor is positioned within the document's character grid or token stream (`line`, `character`/`pos` offset).

In block-rendered and live-preview editors like Obsidian, the active text cursor position determines whether markdown formatting is masked as visual widgets or unmasked as raw editable text.
